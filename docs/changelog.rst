Version 1.0.0 (2026-01-28)
==========================

Initial release of STRATUM platform.

Features
--------

- Complete authentication system
- Project management with team collaboration
- Notes with rich text and attachments
- Hierarchical file management with versioning
- Archaeological forms (Context, Stratigraphic, Artifacts)
- GPS mapping with boundaries
- Real-time WebSocket updates
- Activity feed and audit logs
- Invite system with codes
- 3D model viewer (GLB/GLTF)
- Privacy controls for files
- Multi-platform support (Web, iOS, Android)

Technical
---------

- FastAPI backend with PostgreSQL
- React Native + Expo frontend
- MinIO object storage
- Firebase Authentication
- Socket.IO for real-time features
- Alembic for database migrations
