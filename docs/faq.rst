General
=======

What is STRATUM?
----------------

STRATUM is a comprehensive digital platform for archaeological site management, documentation, and collaboration.

Is STRATUM free?
----------------

Stratum is currently an open-source project and will remain that way until after its parent competition concludes. Future pricing models are yet to be determined.


Technical
=========

What platforms are supported?
------------------------------

- Web (all modern browsers)
- iOS (14+)
- Android (8+)

Can I use STRATUM offline?
---------------------------

Yes, STRATUM supports offline mode with automatic sync when online.

How is my data stored?
-----------------------

- Metadata: PostgreSQL database
- Files: MinIO object storage (S3-compatible)
- Authentication: Firebase

Is my data secure?
------------------

Yes, STRATUM uses:

- HTTPS encryption
- Secure authentication
- Role-based access control
- Regular backups
